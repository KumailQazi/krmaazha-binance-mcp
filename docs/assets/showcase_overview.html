class PointInTimeUniverse:
  """Garantiza que en fecha t sólo existan contratos listados en o antes de t."""
  def get_members(self, as_of_date: date) -> frozenset[str]:
    active = {s for s, meta in self._symbols.items()
              if meta.listing_date <= as_of_date and (meta.delisting_date is None or as_of_date < meta.delisting_date)}
    return frozenset(active - self.MULTIPLIER_RENAMED)
  • Point-in-time filtering: absolute anti-survivorship bias across all historical backtest dates.
  • Denomination-multiplier symbols isolated to prevent synthetic +99,900% return anomalies.
